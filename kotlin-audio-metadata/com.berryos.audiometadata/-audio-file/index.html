AudioFile

class AudioFile

Mutable metadata of one audio file.

High-level properties and the format-specific tag exposed in vorbis edit the same state, so a change made through one view is immediately visible in the other. save writes the state back and leaves everything that was not edited untouched.

artworks is null when the file was opened without pictures; save then preserves the embedded ones. Set it to an empty list to remove them.

The file and its low-level tag views share mutable state and are not thread-safe; do not edit them concurrently.
