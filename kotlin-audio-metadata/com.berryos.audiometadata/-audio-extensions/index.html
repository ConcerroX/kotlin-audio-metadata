AudioExtensions

class AudioExtensions

Well-known tags that are not part of the core cross-format model.

They live in their own namespace so callers can tell them apart from AudioFile standard properties. Storage differs per container; see each property's KDoc. Unknown or vendor-specific keys are deliberately not mapped here and stay reachable through the format-specific tag APIs.
