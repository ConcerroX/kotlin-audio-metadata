Mp4Tag

class Mp4Tag

Mutable view of the iTunes ilst metadata.

Typed properties cover the common fields. Every other entry is available through items and can be edited with setItem, addItem, removeItem, setFreeform and removeFreeform.

The tag is mutable and not thread-safe. Mp4Item.data is a read-only view.
